# ScreenMateCreator <br>
![Демонстрация работы программы](https://sun9-36.vkuserphoto.ru/s/v1/ig2/UM3tU__am2A07kgrDPcoSiXRItVxzC7kDAEY13JwOVifEAqc829RqiOmI5b1eq6aZtFe9ApEVOZ38LKf5EAT8B2Q.jpg?quality=95&as=32x18,48x27,72x41,108x61,160x91,240x136,360x204,480x272,540x306,640x363,720x408,1080x613,1280x726,1440x817,1608x912&from=bu&cs=1280x0) <br>

ScreenMateCreator-создание скринмейтов из разных файлов анимаций и картинок. Creating screenshot memes from various animation and image files.<br>
Персонажа/скринмейт можно собрать в виде отдельного независимого exe-файла(программы), если вы хотите со всеми поделиться каким-то созданным персонажем-скринмейтом.<br>
*<br>
Создавать персонажей/скринмейты можно:<br>
из анимированных файлов в формате gif, json, tgs, webm с прозрачным фоном.<br>
-из последовательности png-файлов(покадровая анимация).<br>
*<br>
У программы есть свой плеер медиафайлов форматов gif, json, tgs, webm, куда можно перетащить файл, посмотреть его анимацию, и тут же нажать кнопку "Сделать скринмейтом".<br>

/
Create screenmates from different animation and image files. Creating screenshot memes from various animation and image files.
The character/screenmate can be assembled as a separate independent exe file (program) if you want to share some created screenmate character with everyone.
*
You can create characters/screenmates
from animated files in gif, json, tgs, or webm format with transparent backgrounds.
-from a sequence of png files (frame-by-frame animation).
*
The program has its own media player for files in the gif, json, tgs, and webm formats, where you can drag and drop a file, view its animation, and immediately click the “Make screenshot” button. <br>
